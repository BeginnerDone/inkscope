# InkScope UI

界面使用真正的 shadcn/ui（官方 `@shadcn` 注册表、Radix Nova 预设）与 Tailwind CSS v4。配置见根目录 `components.json`，组件源码保存在 `src/components/ui/`，通过官方 CLI 维护。

## 设计约定

- 中性浅色桌面工作台；优先呈现书籍、书源、搜索结果和报告内容。
- 页面标题约 22–24px，控件沿用 Nova 的紧凑尺寸；正文阅读使用 16px 字号与舒适行距。
- 使用语义色变量、细边框、小圆角；不叠加装饰性渐变、粗选中边、大宣传标题。
- Button、Input、Checkbox、Select、Tabs、Dialog、AlertDialog、Sidebar、Card、Progress 等直接组合 shadcn 组件。新增控件先检查已有组件，避免另写一套样式。
- `styles.css` 的 `workspace` 层负责业务布局与长篇报告排版；控件颜色、焦点、禁用与交互状态由组件及主题控制。该层排在 Tailwind utilities 之后，使列表行、搜索组的业务布局不被默认高度和宽度压缩。
- 支持键盘操作、窗口缩放与减少动态效果设置。对话框提供标题、焦点限制、Escape 关闭及触发位置焦点恢复。
- 所有字体资源随应用打包，不依赖在线字体服务。

## 文件结构

`HomeView`、`ImportView`、`SourceSearch`、`ReaderView`、`SearchModal`、`SettingsModal` 各自负责对应工作区。`AppSidebar` 与 `BookStatus` 复用统一导航和状态。`App.tsx` 负责应用状态和报告编排，`IdeasView` 保持旧报告与 v2 灵感兼容。

本轮保留 Tauri 命令名、参数、书籍数据结构、分析算法与原创灵感生成流程。搜索弹窗独立维护搜索结果，避免筛选污染书架；同名结果按书源与地址共同识别。

## 验证

```sh
npm run build
npx playwright install chromium
npm run test:ui
```

已有 Chromium 时，可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定可执行文件。测试运行在隔离浏览器中，模拟 Tauri bridge；不访问真实书库、第三方书源或付费模型。截图与失败 trace 写入已忽略的 `test-results/`。

覆盖书架搜索与删除、设置与键盘弹窗、书源选择/搜索/失败/空状态/预览、文本导入参数、阅读翻章/导出、报告与 v2 平台筛选，以及 1280、980、390px 窗口。构建和浏览器测试不等于真实书源联网、DeepSeek 生成质量或原生 WebView 验收；客户端使用 `npm run tauri` 查看。

## 书源搜索工作台（2026-10-02）

- 搜索方式支持书名/关键词与作者。作者名仍提交到各书源现有搜索地址，再按返回的作者字段匹配；不支持作者检索或没有作者字段的源可能无结果。当前继续读取各源搜索首页、最多 20 项，不承诺列出作者的全部作品。
- 保留单次 60 源上限和后端 12 并发、25 秒请求超时。大量全选会增加请求量与等待，故不提供无上限全选。书源管理弹窗以每页 50 项访问全部可搜索源，支持筛选、只看已选、本页补选与清空，移除原先前 300 项展示截断。
- 搜索和书源入口集中在顶部，结果区独立；书籍行打开 shadcn Dialog，在窗口内切换简介、目录与试读，底部固定导入范围、阅读权限和导入动作。关闭后恢复原结果焦点。同步保留仍有效的选择。
- 封面使用源返回的 HTTP(S) 地址并懒加载；不存在或加载失败时回退书本图标。不把空封面解析成搜索页面地址；没有作者规则时也保持作者为空。原生 CSP 仅扩展 img-src 的 HTTP(S) 图片权限，脚本及连接限制保持原状。需要登录、防盗链或不被系统接受的图片仍可能无法显示。
- 本轮浏览器验证覆盖 420 源分页与上限、作者参数、好/坏封面、关闭读取中的预览、预览焦点恢复与导入参数；Rust 覆盖作者匹配与 HTML 搜索规则提取、相对/缺失封面。模拟 bridge 的测试不代表所有真实第三方源可用。

## 字数显示（2026-10-02）

本地书籍继续使用保存正文的 Unicode 字符计数（包含标点、数字、空格和换行；导入时沿用原有首尾空白清理）。界面统一称为“字数”，使用“万字”，最多保留两位小数；非零但不足 100 字显示“不足 0.01 万字”。书架悬停可查看精确数量。粘贴导入前端按 Unicode 码点计数，与 Rust `chars().count()` 一致，避免 Emoji 被算两次。

搜索结果从 `ruleSearch.wordCount` 读取并解析书源返回的字数，支持纯数字、千分位、万/亿及 K/W/M 单位。未提供规则、字段缺失或无法明确解析时返回空值并显示“字数未知”；已提供时显示“书源约 ×× 万字”。书源统计不能保证包含标点，导入后以本地保存正文计数为准；为展示字数不会额外下载全文。
